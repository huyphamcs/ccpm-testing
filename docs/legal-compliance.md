## 1. Privacy Policy Requirements

### 1.1 Privacy Policy Presence
- [ ] Privacy policy page created and accessible
- [ ] Link to privacy policy in footer
- [ ] Link to privacy policy in forms (near consent)
- [ ] Link to privacy policy in cookie banner
- [ ] Privacy policy dated with last update
- [ ] Previous versions archived (if applicable)

### 1.2 Privacy Policy Content Requirements
- [ ] Company/entity name and contact information
- [ ] Types of personal data collected
- [ ] Purpose of data collection
- [ ] Legal basis for processing (GDPR requirement)
- [ ] Data retention periods
- [ ] Third-party data sharing described
- [ ] User rights explained (access, deletion, etc.)
- [ ] Cookie policy included or referenced
- [ ] Data security measures described
- [ ] International data transfers addressed
- [ ] Children's privacy addressed (COPPA compliance)
- [ ] How to contact privacy officer/DPO
- [ ] How policy changes will be communicated
- [ ] Effective date clearly stated

### 1.3 Privacy Policy Review
- [ ] Reviewed by legal counsel
- [ ] Complies with applicable laws (GDPR, CCPA, etc.)
- [ ] Written in clear, plain language
- [ ] No contradictions with actual practices
- [ ] Accurate representation of data practices
- [ ] Updated within last 12 months

## 4. GDPR Compliance Verification

### 4.1 Data Collection Transparency
- [ ] Clear notice at point of collection
- [ ] Purpose of collection explained
- [ ] Legal basis identified (consent, contract, etc.)
- [ ] Mandatory vs optional fields marked
- [ ] Data recipients disclosed
- [ ] International transfers disclosed
- [ ] Retention period stated
- [ ] No pre-checked boxes for consent

### 4.2 User Consent Mechanisms
- [ ] Explicit consent obtained (not implied)
- [ ] Consent requests clear and specific
- [ ] Separate consent for different purposes
- [ ] Easy to withdraw consent
- [ ] Consent withdrawal has same ease as granting
- [ ] Records of consent maintained
- [ ] No consent bundling/forced consent
- [ ] Parental consent for children under 16

### 4.3 Right to Be Forgotten Implementation
- [ ] Data deletion request process documented
- [ ] Users can request data deletion
- [ ] Deletion request form/contact available
- [ ] 30-day response timeline documented
- [ ] Process for verifying deletion requests
- [ ] Third-party data deletion coordinated
- [ ] Deletion exceptions documented (legal holds, etc.)
- [ ] Confirmation provided after deletion

### 4.4 Data Processing Documentation
- [ ] Records of processing activities (ROPA) maintained
- [ ] Data Protection Impact Assessment (DPIA) completed
- [ ] Data processing agreements with vendors
- [ ] Sub-processor list maintained
- [ ] Data breach notification procedure documented
- [ ] DPO appointed (if required)
- [ ] DPO contact information published
- [ ] EU representative appointed (if required)

### 4.5 User Rights Support
- [ ] Right to access data (data export)
- [ ] Right to rectification (data correction)
- [ ] Right to erasure (deletion)
- [ ] Right to restrict processing
- [ ] Right to data portability
- [ ] Right to object to processing
- [ ] Rights request form available
- [ ] Process for fulfilling requests within 30 days

## 8. Email Marketing Compliance

### 8.1 CAN-SPAM Act (US)
- [ ] Clear identification as advertisement (if applicable)
- [ ] Accurate "From" information
- [ ] Honest subject lines
- [ ] Physical mailing address in footer
- [ ] Clear unsubscribe mechanism
- [ ] Unsubscribe honored within 10 days
- [ ] No transfer of opt-out emails
- [ ] Third-party compliance monitored

### 8.2 GDPR Email Marketing (EU)
- [ ] Explicit consent obtained (no pre-checked boxes)
- [ ] Double opt-in implemented (recommended)
- [ ] Purpose of emails clearly stated
- [ ] Easy unsubscribe in every email
- [ ] Records of consent maintained
- [ ] Preference center available
- [ ] Consent separate from other agreements

### 8.3 CASL (Canada Anti-Spam Law)
- [ ] Express consent obtained (if applicable)
- [ ] Sender identification clear
- [ ] Unsubscribe mechanism in every message
- [ ] Consent records maintained

### 8.4 Newsletter Signup Compliance
- [ ] Clear description of what user will receive
- [ ] Frequency disclosed
- [ ] Easy to opt-out
- [ ] Privacy policy linked
- [ ] No sale of email lists
- [ ] Secure email storage
