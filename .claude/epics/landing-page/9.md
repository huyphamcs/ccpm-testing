# Task: Analytics & SEO Implementation

## Description
Add Google Analytics 4 tracking with custom events (CTA clicks, form submissions, scroll depth), implement SEO metadata, structured data (JSON-LD), Open Graph and Twitter Card tags. This task ensures the landing page is discoverable, trackable, and shareable.

## Acceptance Criteria
- [ ] Google Analytics 4 installed and tracking pageviews
- [ ] Custom events tracking: CTA clicks, form submissions, scroll depth (25%, 50%, 75%, 100%)
- [ ] SEO metadata for all pages (title, description, keywords)
- [ ] Structured data (JSON-LD) for Organization and WebSite implemented
- [ ] Structured data validates with Google Rich Results Test
- [ ] Open Graph tags for social sharing (Facebook, LinkedIn)
- [ ] Twitter Card tags implemented and validated
- [ ] sitemap.xml generated
- [ ] robots.txt configured properly

## Technical Details
- Implementation approach:
  - Install next-google-analytics or gtag.js
  - Create analytics wrapper for custom event tracking
  - Use Next.js metadata API for SEO tags
  - Implement JSON-LD structured data components
  - Generate sitemap dynamically or statically
  - Configure robots.txt for proper crawling

- Key considerations:
  - GDPR compliance for analytics (cookie consent)
  - Performance impact of analytics scripts
  - Proper event naming conventions
  - Schema.org vocabulary for structured data
  - Dynamic metadata for different pages/sections

- Files affected:
  - /src/app/layout.tsx (GA4 script, metadata)
  - /src/components/analytics/GoogleAnalytics.tsx
  - /src/lib/analytics.ts (event tracking utilities)
  - /src/components/seo/StructuredData.tsx
  - /src/app/sitemap.ts
  - /public/robots.txt
  - /src/app/opengraph-image.tsx (optional)
