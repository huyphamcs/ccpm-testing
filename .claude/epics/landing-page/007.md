# Task: API Routes & Backend Integration

## Description
Implement API routes (/api/signup, /api/demo, /api/newsletter) with rate limiting, CSRF protection, input sanitization, and email service integration (Formspree fallback). This task establishes the backend infrastructure for handling user interactions from the landing page, ensuring security and reliability.

## Acceptance Criteria
- [ ] All API endpoints (/api/signup, /api/demo, /api/newsletter) implemented and working
- [ ] Rate limiting configured (10 requests/minute per IP)
- [ ] Server-side validation for all inputs (email, name, message)
- [ ] CSRF protection implemented
- [ ] Input sanitization preventing XSS/injection attacks
- [ ] Email service integration with Formspree fallback
- [ ] Email confirmations sent successfully
- [ ] Robust error handling with appropriate HTTP status codes
- [ ] API responses follow consistent JSON format

## Technical Details
- Implementation approach:
  - Use Next.js API routes for serverless functions
  - Implement rate limiting with redis or in-memory store
  - Use express-validator or zod for input validation
  - Integrate next-csrf for CSRF protection
  - Primary email service with Formspree as fallback
  - Error logging and monitoring setup

- Key considerations:
  - Security-first approach for all endpoints
  - Graceful degradation with fallback email service
  - Rate limiting to prevent abuse
  - Proper error messages without exposing sensitive info
  - CORS configuration for API endpoints

- Files affected:
  - /src/app/api/signup/route.ts
  - /src/app/api/demo/route.ts
  - /src/app/api/newsletter/route.ts
  - /src/lib/rate-limiter.ts
  - /src/lib/email-service.ts
  - /src/lib/validation.ts
  - /src/middleware.ts (for CSRF)
