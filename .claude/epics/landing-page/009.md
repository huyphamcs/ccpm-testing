# Task: Performance & Accessibility Optimization

## Description
Optimize images (WebP/AVIF, lazy loading), implement code splitting, run Lighthouse CI, fix accessibility issues (WCAG 2.1 AA), ensure performance budget (<1MB total, <200KB JS). This task ensures the landing page is fast, accessible, and meets quality standards.

## Acceptance Criteria
- [ ] Lighthouse score 90+ for Performance
- [ ] Lighthouse score 90+ for Accessibility (target 95+)
- [ ] Lighthouse score 90+ for Best Practices
- [ ] Lighthouse score 90+ for SEO
- [ ] Cumulative Layout Shift (CLS) < 0.1
- [ ] Largest Contentful Paint (LCP) < 2.5s
- [ ] First Input Delay (FID) < 100ms
- [ ] Total bundle size < 1MB
- [ ] JavaScript bundle < 200KB
- [ ] 0 axe accessibility violations
- [ ] WCAG 2.1 AA compliance verified
- [ ] All images optimized (WebP/AVIF with fallbacks)
- [ ] Lazy loading implemented for below-fold content

## Technical Details
- Implementation approach:
  - Use Next.js Image component for automatic optimization
  - Configure next.config.js for WebP/AVIF formats
  - Implement dynamic imports for code splitting
  - Add lazy loading for images and components
  - Run Lighthouse CI in GitHub Actions
  - Use axe-core for accessibility testing
  - Optimize fonts (preload, font-display: swap)
  - Minimize third-party scripts impact

- Key considerations:
  - Balance optimization with visual quality
  - Maintain accessibility during optimization
  - Performance budget enforcement in CI
  - Browser compatibility for modern formats
  - Critical CSS inlining if needed
  - Reduce main thread blocking time

- Files affected:
  - /next.config.js (image optimization config)
  - /src/components/** (lazy loading, code splitting)
  - /src/app/layout.tsx (font optimization)
  - /.github/workflows/lighthouse-ci.yml
  - /lighthouserc.json (budget configuration)
  - /src/styles/** (CSS optimization)
  - All image files in /public
